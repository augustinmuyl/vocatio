# Vocatio

Vocatio is a full-stack web application that helps students discover, track, and engage with community service opportunities (mostly with high school community-hours requirements in mind).

## Project Structure

```text
.
├── backend
│   ├── app
│   │   ├── alembic
│   │   │   └── versions
│   │   ├── api
│   │   │   └── routes
│   │   ├── core
│   │   ├── db
│   │   ├── models
│   │   └── schemas
│   └── tests
└── frontend
    ├── public
    └── src
        ├── app
        ├── components
        │   └── ui
        └── lib
```
